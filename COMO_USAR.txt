-------------------------------------------------------------------
COMO EXECUTAR NO ROBLOX STUDIO:
-------------------------------------------------------------------
Opção A (Sistema Modular Completo - Cliente):
1. Copie a pasta 'ModularSystem' para:
   StarterPlayer -> StarterPlayerScripts (no Explorer do Roblox Studio).
2. Pressione Play (F5).
3. A interface abrirá no centro da tela.
   - Pressione [HOME] ou [RightShift] para abrir/fechar.
   - Navegue pelas 8 abas na barra lateral esquerda.
   - Observe o badge dinâmico do Watchdog na barra superior.
   - Segure o Botão Direito do Mouse (RMB) para focar no alvo detectado.

Opção B (Testes Unitários no Console):
1. Crie um Script normal dentro de ServerScriptService.
2. Cole o conteúdo de 'MainTestRunner.lua'.
3. Pressione Run (F8) e abra o Output (Exibir -> Saída).
4. Verifique a lista de validações de SimConfig, VectorTracker e Heurísticas de Anomalia.

Opção C (Arquivo Único Standalone):
1. Execute 'DeepHat_Standalone.lua' via Command Bar ou executor local.
